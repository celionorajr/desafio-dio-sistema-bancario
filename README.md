# 🚀 Sistema Bancário - Digital Innovation One (DIO) - NTT DATA

Este repositório contém a solução do desafio proposto no curso **Engenharia de Dados com Python** da **NTT DATA** na **Digital Innovation One (DIO)**. O objetivo é desenvolver um sistema bancário simples utilizando Python, com funcionalidades básicas de depósito, saque e extrato.

## 📌 Funcionalidades

- **Depósito**: Permite adicionar valores positivos à conta bancária.
- **Saque**: Limite de **3 saques diários**, com um valor máximo de **R$ 500,00 por saque**.
- **Extrato**: Lista todas as movimentações realizadas na conta e exibe o saldo atual.

## 🛠 Tecnologias Utilizadas

- Python 3.x
